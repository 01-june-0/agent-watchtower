# 에이전트 워치타워

이 컴퓨터에서 돌아가는 Claude Code 세션이 지금 무엇을 하는지 보여주는 로컬 읽기 전용 대시보드입니다. 메인 세션, 하위 에이전트, 조언자 호출, 도구 사용, 실시간 로그를 터미널 느낌의 흐름도로 그립니다.

[English README](README.md)

- **읽기 전용.** 대시보드는 Claude Code가 이미 남기는 세션 기록 파일을 읽기만 합니다. 기록이나 Claude Code 설정을 고치지 않습니다. (설정에 쓰는 것은 따로 실행하는 `setup --yes` 명령뿐입니다.)
- **로컬 전용.** 서버는 `127.0.0.1`에서만 열리고 이 컴퓨터 밖으로 아무것도 보내지 않습니다. 계정, 사용 통계 수집, 외부 요청이 없습니다.
- **의존성 없음.** 설치할 패키지 없이 Node.js만 있으면 됩니다.

## 명령별로 하는 일

| 명령 | 하는 일 |
|---|---|
| `npx agent-watchtower` | 대시보드만 띄웁니다. 기록을 읽기만 하고 설정은 건드리지 않습니다. |
| `npx agent-watchtower setup` | Claude Code 설정에 무엇을 추가할지 보여 주기만 합니다. 아무것도 바꾸지 않습니다. |
| `npx agent-watchtower setup --yes` | 실제로 추가합니다: `advisorModel`, `critic`·`scout` 하위 에이전트, 완료 전 critic 검토 규칙 |
| 플러그인 명령 `/agent-watchtower:start` | 대시보드만 띄웁니다. setup은 실행하지 않습니다. |

**자동으로 설정하는 것은 없습니다.** 대시보드를 설치하거나 띄워도 Claude Code 설정은 바뀌지 않습니다. 설정을 바꾸는 것은 직접 실행하는 `setup --yes` 뿐이며, 일부러 이렇게 나눴습니다.

- 조언자는 메인 모델에 더해 더 강한 모델을 부르므로 사용량이 늘어납니다. critic 규칙은 모든 Claude Code 세션의 작업 방식을 바꿉니다. 둘 다 사용자가 고를 일입니다.
- `--yes` 를 붙여도 이미 있는 파일과 값(내용이 다른 `critic.md`, 이미 정해 둔 `advisorModel`)은 그대로 두고, `settings.json` 은 바꾸기 전에 백업합니다.
- 조언자는 계정이나 요금제에 따라 쓸 수 없을 수 있습니다. 그래도 setup은 하위 에이전트와 규칙을 추가하고, 조언자 패널만 숨겨집니다.

## 실행

Node.js 22 이상이 필요합니다.

```bash
npx agent-watchtower
```

서버가 뜨고 브라우저에서 `http://127.0.0.1:4477`이 열립니다. 포트가 쓰이고 있으면 다음 빈 포트를 쓰고 그 주소를 알려 줍니다. 워치타워가 이미 떠 있으면 그 화면만 엽니다.

한 번 설치해 두고 쓰려면:

```bash
npm install -g agent-watchtower
agent-watchtower
```

### Claude Code 플러그인으로

```
/plugin marketplace add 01-june-0/agent-watchtower
/plugin install agent-watchtower@agent-watchtower
/agent-watchtower:start
```

### 옵션

| 옵션 | 환경 변수 | 기본값 | 뜻 |
|---|---|---|---|
| `-p, --port <n>` | `AGENT_WATCHTOWER_PORT` | `4477` | 사용할 포트. 직접 정한 경우에는 겹치면 다른 포트를 고르지 않고 끝납니다. |
| `--hours <n>` | `WINDOW_HOURS` | `24` | 최근 n시간 안에 활동한 세션만 추적합니다. |
| `--dir <경로>` | `CLAUDE_PROJECTS_DIR` | `~/.claude/projects` | 기록 폴더. `CLAUDE_CONFIG_DIR`도 따릅니다. |
| `--no-open` / `--open` | | 열기 | 브라우저를 열지 여부. |

화면은 영어와 한국어를 지원합니다. 브라우저 언어를 따르며, 제목줄의 단추나 주소의 `?lang=en` / `?lang=ko`로 바꿀 수 있습니다.

## 같은 화면을 보려면

화면에 무엇이 채워지는지는 Claude Code를 어떻게 쓰는지(데스크톱 앱 또는 VS Code, 조언자, 하위 에이전트)에 달려 있습니다. 워치타워를 만든 환경의 설정을 따라 하려면:

```bash
npx agent-watchtower setup        # 추가할 내용만 보여 줌
npx agent-watchtower setup --yes  # 적용
```

각 설정이 하는 일과 손으로 하는 방법은 [docs/SETUP.ko.md](docs/SETUP.ko.md)에 있습니다.

## 화면 구성

- **세션 목록**: 추적 범위 안에서 활동한 세션과 상태(작업 중 / 입력 대기 / 휴면), 도구 호출 수, 하위 에이전트 수, 오류 수. 세션을 고정하지 않으면 작업 중인 세션을 따라갑니다.
- **흐름도**: 메인 세션 → 판단 층 → 하위 에이전트 → 메인으로 복귀. 조언자를 쓰는 세션(조언자 모델이나 자문 기록이 있음)에서는 왼쪽에 조언자 패널이 나옵니다.
- **많이 쓴 도구**와 최근 200건의 **세션 로그**(메인만 / 도구만 / 오류만으로 거를 수 있음).

## 측정값이 아니라 추정값인 것

기록 파일에는 상태, 확신도, 진행률이 적혀 있지 않아서 화면의 몇몇 값은 추정입니다. 화면에 추정임을 적어 두었고, 표본이 부족하면 값을 내지 않습니다.

| 값 | 계산 방법 |
|---|---|
| 세션 상태 | 마지막 활동 시각 기준(15초 / 3분 / 30분). 강제 종료된 세션은 최대 30분 동안 작업 중으로 보일 수 있습니다. |
| 판단 층과 `p` | 최근 도구 호출 20건이 한 파일이나 한 도구에 얼마나 모여 있는지. 모델 내부의 확신도가 **아닙니다**. |
| 자문 시점 | 자문 직전의 도구 호출로 추정합니다. 조언 내용은 기록에 암호화되어 있습니다. |
| 하위 에이전트 진행률 | 같은 종류의 완료된 에이전트가 쓴 도구 호출 중앙값과 견줍니다. 완료 기록이 2건 이상 있어야 합니다. |

## 호환성

에이전트 워치타워는 Claude Code가 `~/.claude/projects` 아래에 남기는 기록 형식에 기대고 있습니다. 이 형식은 내부용이라 Claude Code 버전에 따라 바뀔 수 있습니다. 모르는 줄은 건너뛰므로, 형식이 바뀌면 프로그램이 죽는 대신 값이 비어 보입니다.

- macOS에서 Claude 데스크톱 앱과 VS Code 확장(Claude Code 2.1.317~2.1.321) 기준으로 만들었습니다.
- 윈도우와 리눅스는 동작할 것으로 보지만 아직 확인하지 못했습니다. 제보를 환영합니다.

## 개인정보와 보안

화면에 프롬프트, 명령, 파일 이름의 요약이 나오므로 이 컴퓨터 밖으로 나가지 않게 만들었습니다.

- `127.0.0.1`에서만 열리고, `Host`가 `localhost` / `127.0.0.1`이 아닌 요청은 거절
- 다른 사이트에서 보낸 요청과 `GET`이 아닌 요청은 거절
- 외부 자원을 모두 막는 콘텐츠 보안 정책
- 기록 속 문자열은 HTML이 아니라 글자로만 넣음

같은 컴퓨터의 다른 사용자 계정은 `127.0.0.1` 포트에 접속할 수 있습니다. 여러 사람이 함께 쓰는 서버에서는 이 점을 감안해 주세요.
